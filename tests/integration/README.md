# Cross-Language HMAC Integration Tests

Proves that HMAC signatures generated by any SDK language are correctly validated by any other SDK language's server middleware, across the full HTTP stack.

## Test Matrix

4 clients (C#, Python, TypeScript, Go) x 4 servers = 16 combinations.
Each combination tests GET and POST = 32 total assertions.

## Prerequisites

- **.NET 8 SDK** (`dotnet --version`)
- **Python 3.10+** with pip (`python3 --version`)
- **Node.js 18+** with npm (`node --version`)
- **Go 1.21+** (optional, for Go server/client)

Python packages: `fastapi`, `uvicorn`, `httpx` (auto-installed by `run.sh`).

## Running

```bash
cd tests/integration
bash run.sh
```

The orchestrator will:
1. Detect which language runtimes are available
2. Build all projects (C# pre-build, TS SDK compile, npm install)
3. Start all servers in the background
4. Wait for each server to be ready (TCP port check)
5. Run each client sequentially
6. Print a results matrix
7. Exit 0 if all pass, 1 if any fail

## Configuration

`config.json` contains shared secrets and port assignments. All servers and clients read from this file.

Each client sends `X-Harden-Client-Id` with its identity (e.g., `python-client`). Servers look up the client's shared secret in their Clients dictionary to validate the signature.

## Architecture

```
Client (language A)                    Server (language B)
  |                                       |
  |-- sign(method, path, body, ts) ------>|
  |   + X-Harden-Signature               |-- validate(method, path, body,
  |   + X-Harden-Timestamp               |      signature, timestamp)
  |   + X-Harden-Client-Id               |
  |   + X-Harden-Signed-Headers          |-- look up secret by Client-Id
  |                                       |
  |<-- 200 OK (or 401 if mismatch) ------|
```

## Troubleshooting

- **Port conflict**: Change ports in `config.json`
- **C# slow build**: First run builds all projects; subsequent runs use `--no-build`
- **Python import error**: Ensure you're running from the repo root or that `sdk/python/src` is on PYTHONPATH
- **TypeScript not found**: Run `npm install` in `sdk/typescript/packages/hmac` first, then `npm run build`
- **Server logs**: Check `servers/{language}/server.log` for errors
